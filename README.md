# Landing Accexuri — Accessories World

Landing page de **Accexuri**, marca de accesorios para motocicletas, desarrollada en **React + Vite** siguiendo el Manual Accexuri 2026.

## Cómo correrla

Requiere Node.js 18 o superior.

```bash
npm install
npm run dev
```

Se abre en http://localhost:5173

## Páginas

Inicio · Nosotros · Líneas · Productos · Rider · Contacto

## Características

- Diseño fiel al manual de marca (paleta neón, tipografías y logos).
- Navegación por páginas con menú fijo y menú adaptado a celular.
- Efectos de parallax y animaciones al hacer scroll.
- Secciones "¿Por qué Accexuri?" y preguntas frecuentes.
- Botón flotante de WhatsApp.
- Formulario de contacto con validación de campos.
- Diseño responsive para computadora, tablet y celular.

## Estructura

```
public/          logos e imágenes
src/
  components/    secciones de la página
  data/          textos y datos de contacto
  lib/           navegación y animaciones
  styles.css     estilos
```
